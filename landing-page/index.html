Dual-Stage DNS-over-HTTPS (DoH) Prober

When a bookmark link fails to respond, traditional tools immediately declare it "dead". BHM-PRO triggers a secondary diagnostic handshake through Cloudflare and Google DoH endpoints to check if the authoritative domain still exists.

  • 🎯 Filters out temporary network dropouts and aggressive WAF bot challenges.
  • 🎯 Confirms NXDOMAIN (unregistered domain) vs HTTP 404 / 500 status codes.
  • 🎯 Smart quarantine: moves dead links into an isolated quarantine folder before any deletion.
